Como funciona a decomposição da chave de acesso

A chave de acesso é um código de 44 dígitos numéricos presente em todos os documentos fiscais eletrônicos emitidos no Brasil. Cada grupo de dígitos carrega uma informação específica:

  • UF/Estado (2 dígitos) — Código IBGE do estado emissor
  • Ano e Mês (4 dígitos) — Data de emissão no formato AAMM
  • CNPJ (14 dígitos) — CNPJ do emitente do documento
  • Modelo (2 dígitos) — Tipo do documento fiscal (55=NF-e, 57=CT-e, 65=NFC-e, etc.)
  • Série (3 dígitos) — Série do documento
  • Número (9 dígitos) — Número sequencial do documento
  • Tipo de Emissão (1 dígito) — Normal, contingência, SCAN, etc.
  • Código Numérico (8 dígitos) — Código aleatório de segurança
  • Dígito Verificador (1 dígito) — Calculado pelo módulo 11

Perguntas frequentes sobre chave de acesso

O que é a chave de acesso de um documento fiscal eletrônico?

A chave de acesso é um código numérico de 44 dígitos que identifica de forma única cada documento fiscal eletrônico (NF-e, CT-e, NFC-e, MDF-e, entre outros) emitido no Brasil. Ela contém informações como o estado de emissão, data, CNPJ do emitente, modelo do documento, série, número e o dígito verificador.

Quantos dígitos tem uma chave de acesso?

A chave de acesso possui exatamente 44 dígitos numéricos. Cada grupo de dígitos representa uma informação específica: os 2 primeiros indicam o estado (UF), os 4 seguintes indicam ano e mês de emissão, os 14 seguintes o CNPJ, e assim por diante até o último dígito, que é o verificador.

Como é composta a chave de acesso da NF-e?

A chave de acesso da NF-e é composta pelos seguintes campos, nesta ordem: Código da UF (2 dígitos), Ano e Mês de emissão (4 dígitos no formato AAMM), CNPJ do emitente (14 dígitos), Modelo do documento (2 dígitos), Série (3 dígitos), Número do documento (9 dígitos), Tipo de emissão (1 dígito), Código numérico (8 dígitos) e Dígito verificador (1 dígito).

Como validar o dígito verificador de uma chave de acesso?

O dígito verificador é calculado usando o módulo 11 sobre os 43 primeiros dígitos da chave. Os pesos são aplicados da direita para a esquerda, na sequência 2, 3, 4, 5, 6, 7, 8, 9, repetindo ciclicamente. Se o resto da divisão por 11 for 0 ou 1, o dígito verificador é 0; caso contrário, é 11 menos o resto. Nossa ferramenta faz essa validação automaticamente.
